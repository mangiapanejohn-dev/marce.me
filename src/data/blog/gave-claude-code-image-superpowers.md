Yoo fellow coders and terminal artists! Marc here 😜

Small, fun, very *meta* one today: I open-sourced **claude-imagegen**, a skill that gives Claude Code the one superpower it was missing — making images. And to prove it works, **every image in this post was generated by the skill itself**, from inside my terminal, while writing this post. The snake eats its own tail and paints a portrait of it 🐍🎨.

The itch: Codex CLI ships with a built-in `image_gen` tool. Claude Code — my daily driver — has *nothing*. Every time I needed a quick hero image, an icon, or a placeholder illustration, I had to leave the terminal, open some web UI, download, rename, drag into the project… for a thirty-second task. Claude Code has this lovely skills system sitting right there, so: classic Marc move. Nobody wired it up, so I wired it up.

### What it actually does

You just talk to Claude Code like normal — "make me a landing-page hero with a cozy cabin at dawn" — and the skill routes it through a bundled Python CLI to OpenAI's `gpt-image-2`, builds a properly structured prompt (scene, style, composition, lighting, constraints), and drops the finished PNG straight into your project at the path you wanted. Generate, edit an existing image, or batch a whole set of assets in one go. No tab-switching, no download folder archaeology.

### My favorite hack: transparent cutouts

Here's the fun part. `gpt-image-2` flat out **doesn't support transparent backgrounds**. So the skill cheats like a movie studio: it generates your subject on a flat chroma-key green screen, then a local script keys the green out into real alpha — with edge softening and de-spill so you don't get that radioactive green fringe.

There's also a `/image-c` setup flow that stores your OpenAI key safely in a local config (chmod 600, never echoed back, works with relay endpoints too), so the whole thing is a one-time setup and then it just… works, in every session, in every project.

Credit where it's due: this started as an adaptation of Codex CLI's imagegen skill (Apache 2.0 — license and attribution kept intact in the repo). I rebuilt it around Claude Code's skill conventions, added the key-management flow and the chroma-key pipeline, and put `SKILL.md` at the repo root so installing is literally one line:

```
npx skills add mangiapanejohn-dev/marcyy.me-claude-imagegen
```

Obligatory dev blooper: my first chroma-key test subject was a green frog. On a green background. The keying script very obediently deleted the entire frog and handed me a perfectly transparent, completely empty PNG. Ten out of ten for following instructions 😂. That's the day the magenta fallback was born.
