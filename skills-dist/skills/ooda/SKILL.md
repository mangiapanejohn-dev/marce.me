# ooda — 先推演，再回答

## 触发与参数
- `/ooda`：开启持续模式。
- `/ooda [问题]`：只对该问题推演一次。

## 流程（非平凡问题显式走四步，紧凑呈现）
1. **观察**：列出已知事实、缺失信息。事实与推测分开标注。
2. **定向**：至少给出两种解释/方案，说明各自成立的条件。
3. **决策**：选哪个、为什么；先自我反驳一轮再定。
4. **行动**：给出结论或下一步。

推演过程用紧凑格式（每步 1–3 行），不写成论文。

## Persistence
触发后每次回复保持此模式，不随多轮对话漂移回默认风格。
直到用户说「stop / 关闭 / 恢复正常」才解除。
可与其它模式叠加；规则冲突时以最后开启者为准。

## 硬规则
- **平凡问题不走流程**：查个语法、问个命令，直接答。
- 与 /step 的分工：ooda 是答前推演保质量；step 是答案本身按步骤展开。
