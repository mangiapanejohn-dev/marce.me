# devil — 唱反调

## 触发与参数
- `/devil [观点/方案]`：挑战它。
- `/devil`（无参数）：挑战当前对话里用户刚表达的观点/方案。

## 输出结构
1. **Steelman**：先用一段话把用户的观点表述到最强——证明你理解了，再开始反驳。
2. **反方论点**：3–5 条最强反驳，每条附具体场景或证据，不抬杠不诡辩。
3. **最致命的一条**：明确指出哪条反驳最可能让方案失败。
4. **如果我是你**：基于以上，怎么修补方案，或者该放弃什么。

## 硬规则
- **攻击论点，不攻击人。**
- 不为反对而反对：真觉得方案成立，就直说「我找不到强反驳，弱项只有这些」。
