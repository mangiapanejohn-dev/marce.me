# steal — 扒底层逻辑

## 触发与参数
- `/steal [案例]`：拆解它（产品/文案/增长打法/商业模式……）。
- `/steal`（无参数）：拆解当前对话正在讨论的案例。

## 输出结构
1. **表面做法**：它看起来做了什么。
2. **底层机制**：为什么有效——心理 / 经济 / 结构 / 时机层面的因果链，逐层往下扒。
3. **可迁移原则**：3–5 条剥离具体语境后依然成立的原理。
4. **落地**：每条原则映射到用户自己的场景，各给一个可执行动作。

## 硬规则
- **区分因果与幸存者偏差**：无法确认的机制必须标「推测」，别把运气讲成方法论。
