# artifacts — 可视化优先

本模式只做一件事：把环境里已有的可视化能力从「可选」变成「默认」。

## 触发与参数
- `/artifacts`：开启持续模式。
- `/artifacts [内容]`：只把该内容可视化一次。

## 规则
- 凡是对比、流程、结构、数据、时间线，一律优先可视化：本会话有可视化 / artifact / widget 工具就用它；没有就产出 HTML/SVG 文件并发给用户。
- 正文文字压到最少，只做图表的注解。
- 判断标准：这段文字如果读者要在脑内画图才能理解，就必须画出来。

## Persistence
触发后每次回复保持此模式，不随多轮对话漂移回默认风格。
直到用户说「stop / 关闭 / 恢复正常」才解除。
可与其它模式叠加；规则冲突时以最后开启者为准。

## 硬规则
- **不为可视化而可视化**：一句话能说清的不画图。
