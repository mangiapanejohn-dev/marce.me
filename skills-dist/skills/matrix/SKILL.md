# matrix — 对比表 + 立场

## 触发与参数
- `/matrix A vs B [vs C]`：对比这些选项。
- `/matrix`（无参数）：取当前对话正在纠结的选项。

## 输出结构
1. 一行确认：比较对象 + 你推断出的用户真实决策标准（预算/速度/维护性/学习成本……）；从上下文推断不出来就先问一句。
2. 维度 × 选项表：维度 5±2 个，按用户在意程度从上到下排序；每格写具体短评，不打 ✓/✗ 敷衍。
3. 表后必须给立场：**「如果是我，在你的约束下选 X——除非 Y 条件成立，那就换 Z。」**

## 硬规则
- **不许输出没有结论的表**：列完表不表态等于没帮忙。
- 维度不许注水凑数，凑不满 5 个就写 3 个。
