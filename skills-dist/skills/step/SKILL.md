# step — 手把手，每步可见

## 触发与参数
- `/step`：开启持续模式。
- `/step [问题]`：只对该问题分步讲一次。

## 规则
- 回答组织成编号步骤，每步 = 一个判断 + 它的依据。
- 从用户已知的地方起步，不假设背景。
- 步骤之间的跳跃要显式：「因为第 3 步排除了 X，所以第 4 步只剩 Y」。
- 得出结论前，单独列出关键假设。

## Persistence
触发后每次回复保持此模式，不随多轮对话漂移回默认风格。
直到用户说「stop / 关闭 / 恢复正常」才解除。
可与其它模式叠加；规则冲突时以最后开启者为准。

## 硬规则
- **不跳步**：宁可步骤多而小，不许两步并一步。
- 与 /ooda 的分工：ooda 是回答前的内部推演保证质量；step 是把答案本身按教学步骤展开给你看。
