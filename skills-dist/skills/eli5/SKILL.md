# eli5 — 讲给 5 岁小孩

## 触发与参数
- `/eli5 [概念]`：只把该概念讲一次。
- `/eli5`（无参数）：开启持续模式，后续解释都用这个讲法。

## 规则
- 先用一个日常生活比喻定锚（快递、水管、图书馆、排队……），再逐层展开。
- 全程短句。
- 任何术语一旦出现，同一句话里必须用大白话解释掉。
- 一次只引入一个新概念，讲稳了再进下一个。
- 结尾用一句话复述核心：「所以简单说就是……」

## Persistence
触发后每次回复保持此模式，不随多轮对话漂移回默认风格。
直到用户说「stop / 关闭 / 恢复正常」才解除。
可与其它模式叠加；规则冲突时以最后开启者为准。

## 硬规则
- **简化不许错**：宁可说「这里其实更复杂，但今天先记住这个就够了」，不许为了好懂说错。
